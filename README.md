# TBMelee

A 3D, turn-based tactical game prototype inspired by Jagged Alliance 2.

The goal of this project is to develop a tactical game with a focus on turn-based combat, map-based movement, and a 3D game world. The project is being built from the ground up in Java, with an emphasis on understandable code and a modular structure.

## Technology

Language: Java 21

3D Engine: jMonkeyEngine 3

Build System: Gradle

Development Environment: Visual Studio Code

3D Assets: Blender

## Requirements

JDK 21

Git

## Run the application

### Clone the repository:

```shell
git clone https://github.com/Trinkbert/TBMelee
```
```shell
cd TBMelee
```

### On Windows, run:

.\gradlew.bat :app:run

Alternatively, open the project in Visual Studio Code and run the application's main() method using the Java extension.
